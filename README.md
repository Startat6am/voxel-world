# Little Haven — Voxel Pet World

A cozy browser pet prototype built with Three.js and Vite.

## Gameplay
- Click/tap the meadow to send Mochi exploring.
- Feed Mochi an apple to restore fullness.
- Play and cuddle to improve happiness.
- Watch the floating voxel island, pond, trees, flowers and drifting clouds.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The project is a client-side prototype. No account, database, or environment variables are required.
